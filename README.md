# Dra. Verónica Montoya — Medicina estética en Armenia

Sitio web de la Dra. Verónica Montoya (Vite + React + Tailwind + Lenis + Three.js).

- `npm install` y `npm run dev` para verlo en local.
- `npm run build` genera la carpeta `dist`.
- Netlify publica automáticamente cada cambio en `main` (configuración en `netlify.toml`).

Textos en `src/content.ts`. Videos e imágenes en `public/media`.
